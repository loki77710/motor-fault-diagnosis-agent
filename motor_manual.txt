[电机故障条款1]
故障类型：转子不平衡
症状特征：振动频率=1x转速频率（跟转速同步）；振动方向以径向为主，轴向较小；温度可能轻微上升；声音低沉、周期性。
诊断依据：FFT显示1x频率峰值显著高于2x/3x；径向振动幅值大于轴向。
验证方法：动平衡前后对比，校正后1x峰值应显著下降。
维修建议：做动平衡校正；检查转子是否积灰、缺损、键槽松动。
预计维修时间：2-4小时

[电机故障条款2]
故障类型：转子断条
症状特征：电流频谱出现2sf边带（s为转差率，f为电源频率）；振动可能伴随1x和2x；负载时振动加剧，空载时减轻。
诊断依据：电流频谱2sf边带明显；振动幅值随负载增加而增大。
验证方法：断电检查转子导条是否断裂；做电流频谱分析。
维修建议：更换转子或修复断条；检查端环焊接质量。
预计维修时间：6-12小时

[电机故障条款3]
故障类型：气隙偏心
症状特征：振动频率=2x转速频率；可能伴随UMP（不平衡磁拉力）引起的低频振动；电流频谱出现2sf边带。
诊断依据：FFT显示2x峰值突出；电流边带明显；温度可能上升。
验证方法：检查定子与转子间气隙均匀性；测气隙偏差。
维修建议：检查轴承座磨损；重新装配调整气隙；必要时更换轴承。
预计维修时间：4-8小时

[电机故障条款4]
故障类型：定子绕组匝间短路
症状特征：局部温度异常升高；电流谐波增加；振动可能不显著；绝缘性能下降。
诊断依据：绕组温度显著高于其他相；电流谐波THD上升；绝缘电阻降低。
验证方法：测三相电流不平衡度；做绝缘电阻测试；红外热成像。
维修建议：重绕定子绕组或更换定子；检查过载原因。
预计维修时间：8-24小时

[电机故障条款5]
故障类型：定子绕组绝缘老化
症状特征：温升持续偏高；局部放电；绝缘电阻下降；电流出现异常谐波。
诊断依据：绝缘电阻低于标准值；局部放电检测异常；温升趋势持续上升。
验证方法：绝缘电阻测试；局部放电检测；红外测温。
维修建议：更换绕组；改善散热条件；检查负载是否长期超载。
预计维修时间：12-24小时

[电机故障条款6]
故障类型：对中不良
症状特征：振动频率=2x转速频率；径向和轴向振动都较大；温度可能上升。
诊断依据：FFT显示2x峰值突出；轴向振动幅值明显；联轴器两侧振动相位差180度。
验证方法：激光对中仪测量；检查联轴器磨损。
维修建议：重新对中；更换磨损的联轴器弹性元件。
预计维修时间：2-4小时

[电机故障条款7]
故障类型：机械松动
症状特征：高频段能量高，出现多倍频（3x、4x、5x...）；振动方向性明显；可能有冲击声、咔哒声；温度通常正常。
诊断依据：FFT显示高频多倍频成分；时域波形有冲击特征；振动随负载变化不敏感。
验证方法：检查地脚螺栓、轴承座紧固状态；敲击法检查。
维修建议：紧固地脚螺栓；更换磨损的轴承座；检查基础是否开裂。
预计维修时间：1-3小时

[电机故障条款8]
故障类型：电压不平衡
症状特征：三相电流不平衡；负序电流增加；温升；振动可能伴随2x频率。
诊断依据：三相电流偏差超过5%；负序电流分量明显；电网电压不平衡。
验证方法：测量三相电压和电流；检查供电线路。
维修建议：检查供电线路；调整负载分配；安装电压平衡装置。
预计维修时间：1-4小时

[通用诊断条款9]
症状与故障快速对照表：
- 1x频率突出 + 径向为主 → 转子不平衡
- 2x频率突出 + 轴向大 → 对中不良
- 2x频率突出 + 电流边带 → 气隙偏心
- 电流2sf边带明显 → 转子断条
- 高频多倍频 + 冲击声 → 机械松动
- 温度异常 + 电流谐波 → 定子故障
- 三相电流不平衡 → 电压不平衡

[通用诊断条款10]
故障严重程度分级：
- 轻度：振动幅值略高于基线，温度正常，无异常声音 → 加强监测
- 中度：振动幅值明显上升，温度上升5-10°C → 安排近期检修
- 重度：振动幅值大幅上升，温度上升超过10°C，有异响 → 立即停机检修

[正常状态条款11]
故障类型：正常
症状特征：振动1x、2x、3x均低于0.05；电流边带比<0.02；电流谐波能量<0.05；100Hz比<0.02；峭度接近3；峰值因子3-4。
诊断依据：所有振动和电流特征均在正常范围内，无任何故障特征频率突出。
验证方法：连续监测振动和电流趋势，保持稳定即可。
维修建议：无需维修，按常规周期监测。


[电机故障条款12]
故障类型：电机轴承故障（区别于第一个项目的轴承诊断）
症状特征：振动高频段出现轴承特征频率（BPFO/BPFI/BSF/FTF）；温度可能上升；可能伴随异响。
FFT特征：高频能量突出；包络谱中可见轴承特征频率；峭度>3；与不平衡/对中的1x/2x主导不同。
诊断依据：高频冲击 + 轴承特征频率峰值。
验证方法：包络分析；检查润滑状态；测轴承温度。
维修建议：更换轴承；检查润滑脂是否碳化；检查安装对中。
预计维修时间：3-6小时

[电机故障条款13]
故障类型：电机启动异常
症状特征：启动电流过大；启动时间延长；可能伴随嗡嗡声；频繁跳闸。
FFT特征：启动瞬间电流谐波异常；振动在启动阶段出现瞬态冲击。
诊断依据：启动电流超过额定值3倍以上；启动时间超过标准值。
验证方法：测量启动电流曲线；检查转子是否卡涩；检查电源电压。
维修建议：检查转子灵活性；检查电容器（单相电机）；检查接触器。
预计维修时间：2-4小时

[电机故障条款14]
故障类型：电机过热
症状特征：外壳温度持续高于70°C；温升超过环境40°C；绝缘老化加速。
FFT特征：振动可能无明显异常；电流可能略高。
诊断依据：温升趋势持续上升；负载超过额定值。
验证方法：红外测温；检查通风是否堵塞；测量实际负载电流。
维修建议：清理通风道；降低负载；检查冷却风扇。
预计维修时间：1-2小时

[电机故障条款15]
故障类型：变频器驱动下的电机故障
症状特征：变频器报警过流/过压；电机低速时振动加剧；高频谐波引起绝缘老化。
FFT特征：电流频谱出现开关频率边带；振动在特定转速出现共振。
诊断依据：变频器故障码；特定转速下振动峰值。
验证方法：检查变频器参数；测量轴承电流（轴电压）。
维修建议：加装输出电抗器；使用绝缘轴承；调整载波频率。
预计维修时间：4-8小时

[电机故障条款16]
故障类型：轴电压/轴电流腐蚀
症状特征：轴承早期失效；润滑脂变黑；轴承滚道有电蚀纹。
FFT特征：振动初期正常，后期出现轴承特征频率。
诊断依据：轴电压>500mV；轴承电蚀痕迹。
验证方法：测量轴电压；检查轴承滚道。
维修建议：加装碳刷接地；使用绝缘轴承；变频器加装共模滤波器。
预计维修时间：4-6小时

[电机故障条款17]
故障类型：电机冷却系统故障
症状特征：局部过热；温度不均匀；风扇异响。
FFT特征：风扇频率振动；冷却风道堵塞引起的气流噪声。
诊断依据：局部温度异常；风量下降。
验证方法：风速仪测量；检查风扇叶片；检查通风口。
维修建议：清理通风道；更换风扇；检查散热片。
预计维修时间：1-3小时

[电机故障条款18]
故障类型：单相运行（三相电机缺相）
症状特征：电机无法启动或转速下降；电流急剧上升；严重发热；嗡嗡声强烈。
FFT特征：电流出现负序分量；振动加剧；温升迅速。
诊断依据：三相电流严重不平衡（一相为零）；电机温度急剧上升。
验证方法：测量三相电压和电流；检查接触器和熔断器。
维修建议：立即停机；检查供电线路；检查接触器触点。
预计维修时间：1-2小时

[电机故障条款19]
故障类型：负载异常引起的电机故障
症状特征：电机电流超过额定值；温度上升；转速下降；长期过载加速绝缘老化。
FFT特征：电流幅值整体上升；振动幅值增加但频谱结构与基线一致。
诊断依据：电流>额定值10%以上；负载机械阻力增大。
验证方法：测量负载转矩；检查机械传动；检查是否有卡涩。
维修建议：减轻负载；检查传动系统；更换更大功率电机（如需）。
预计维修时间：2-6小时

[电机故障条款20]
故障类型：环境因素引起的电机故障
症状特征：潮湿环境导致绝缘下降；粉尘堆积引起散热不良；腐蚀性气体加速老化。
FFT特征：振动无明显异常；电流可能正常。
诊断依据：绝缘电阻下降；散热效果变差；表面腐蚀。
验证方法：绝缘电阻测试；检查防护等级；检查密封。
维修建议：升级防护等级（IP54→IP65）；加装防潮加热器；定期清理。
预计维修时间：4-8小时

[诊断流程条款21]
标准诊断五步法：
第一步：症状收集——倾听用户描述，提取振动、温度、声音、电流等特征。
第二步：信号分析——振动FFT + 电流频谱，提取客观特征。
第三步：假设生成——基于知识库生成3个最可能假设，按置信度排序。
第四步：假设验证——逐一验证，排除竞争假设。
第五步：结论输出——输出根因、证据链、维修建议。
注意：每一步都可能回到上一步，是循环而非线性。

[诊断流程条款22]
故障分类的判断优先级：
优先级1（电气特征优先）：先看电流特征，因为电流故障（断条、定子、电压）往往有明确的电流判据。
优先级2（振动特征次之）：振动特征用于区分机械故障（不平衡、对中、松动、偏心）。
优先级3（温度特征辅助）：温度异常通常与电气故障或过载相关。
优先级4（声音特征参考）：冲击声指向松动；沉闷声指向不平衡；尖锐声指向轴承。
原则：电气特征优先于振动特征，客观信号优先于用户描述。

[故障树条款23]
电机故障树（从症状到根因）：
振动大 → 
  ├─ 1x突出 → 不平衡
  ├─ 2x突出 → 对中不良 或 气隙偏心
  ├─ 高频冲击 → 机械松动 或 轴承故障
  └─ 无规律 → 检查传感器

温度高 → 
  ├─ 局部高 → 定子故障 或 冷却系统
  ├─ 整体高 → 过载 或 电压不平衡
  └─ 轴承处高 → 轴承故障 或 润滑失效

电流异常 → 
  ├─ 2sf边带 → 转子断条
  ├─ 3次/5次谐波 → 定子故障
  ├─ 100Hz → 电压不平衡
  └─ 三相不平衡 → 缺相 或 电压不平衡

[诊断精度条款24]
提高诊断精度的四个关键：
1. 基线对比——与历史正常状态对比，而非绝对阈值。同一型号电机基线不同。
2. 趋势分析——看变化趋势，而非单一时刻。渐进式退化比突发故障更常见。
3. 多信号交叉验证——振动、电流、温度三个信号都支持才下结论。
4. 排除法——先排除简单故障（传感器、接线、电源），再考虑复杂故障。

[误诊预防条款25]
五种常见误诊及预防：
误诊1：把对中不良当不平衡——原因：只看1x不看2x和轴向。预防：检查1x/2x比值和轴向振动。
误诊2：把电压不平衡当断条——原因：都有电流异常。预防：看是100Hz还是2sf边带。
误诊3：把传感器故障当机械故障——原因：未排查信号源。预防：先检查传感器和接线。
误诊4：把负载变化当故障——原因：未对比基线。预防：对比历史数据和负载记录。
误诊5：把单一故障当复合故障——原因：过度分析。预防：先用排除法判断单一故障。

[数据质量条款26]
数据质量对诊断的影响：
高质量数据（信噪比>20dB）：所有诊断方法都可靠。
中等质量数据（10-20dB）：需要多信号交叉验证。
低质量数据（<10dB）：需要先做信号去噪，否则误诊率高。
数据质量检查清单：
- 传感器是否校准？
- 采样率是否≥2倍最高特征频率？
- 是否有电磁干扰？
- 数据采集时间是否足够长？
原则：数据质量决定诊断上限。

[诊断置信度条款27]
诊断置信度的四个层次：
层次1（>0.9）：三个信号（振动、电流、温度）一致，且符合知识库典型模式。→ 直接下结论。
层次2（0.7-0.9）：两个信号一致，第三个缺失或模糊。→ 输出结论并注明不确定性。
层次3（0.5-0.7）：只有一个信号明确支持，或存在多个竞争假设。→ 输出概率排序。
层次4（<0.5）：信息严重不足。→ 输出"疑似"，建议补充检测。
原则：宁可给出保守的置信度，也不要虚高。

[复合故障条款28]
多故障并发的诊断策略：
常见复合模式：
- 不平衡 + 轴承故障：1x突出 + 高频冲击 → 需要同时处理动平衡和轴承更换
- 对中不良 + 松动：2x突出 + 多倍频 → 先对中，再紧固
- 定子故障 + 电压不平衡：谐波 + 100Hz → 先处理电源问题
诊断方法：
1. 逐一验证每个假设
2. 检查各故障的特征是否共存
3. 优先处理更紧急的故障
4. 考虑故障之间的因果链（如松动导致对中不良）
原则：复合故障诊断需要综合判断，不能简单叠加。

[维护决策条款29]
基于诊断结果的维护决策：
决策1（轻微异常）：继续运行，加强监测（每周一次）。
决策2（中度异常）：计划性停机检修（1-2周内）。
决策3（严重异常）：立即停机检修（24小时内）。
决策4（紧急故障）：立即停机，禁止运行。
判断依据：置信度 + 严重程度 + 故障类型。
特殊情况：
- 若是绝缘类故障，即使轻微也应尽快处理（有安全风险）
- 若是机械类故障，可结合生产计划安排
- 若影响安全生产，无论轻重立即处理

[记录与分析条款30]
诊断记录的规范：
每次诊断应记录：
- 时间戳、设备ID、用户描述
- FFT特征（1x、2x、峭度、边带比、谐波、100Hz比）
- 生成的所有假设及置信度
- 最终结论及证据链
- 维修建议及后续跟踪结果
分析价值：
- 建立设备健康档案
- 发现趋势性变化
- 沉淀诊断经验
- 为新故障提供参考案例
